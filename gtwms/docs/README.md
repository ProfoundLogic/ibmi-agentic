# GT Warehouse Mobile — documentation

Prospect POC for Giant Tiger: a warehouse-floor application on ILE RPG + RPG
Open Access + Profound UI Rich Display files, running inside Genie, responsive
from phone to desktop.

Build library: **`TIGERPOC`**. Branch: **`TIGERPOC`**.

## A note on the screenshots

`screens/` is **evidence, not documentation of intent**. Each image is the
output of a pre-flight run that also asserted no horizontal overflow and audited
every `<%= identifier %>` against the display file's declared fields. Those
checks have caught bugs a clean compile did not — a blank screen, a layout
spilling off the right edge, a field name that silently rendered empty.

Re-generate rather than retouch:

```sh
node gtwms/tools/preflight-item.js      # Item Lookup search + detail
node gtwms/tools/preflight-scnhome.js   # Scan Lab
node gtwms/tools/preflight-ejs.js       # main menu
```
